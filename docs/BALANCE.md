# Balance report

> Generated by `npm run balance` (engine v3, data v2). Do not edit by hand.

**Players:** 2000 seeded random players (`randomAnswers`, seeds 1–2000) with random setups. Each question is
skipped 15% of the time. The last screen (hard preferences, race, classes to skip) and result-page tweaks are cleared,
so this measures what the questions alone do. Random answers are not real players: role options are spread evenly
across roles by design, which alone lifts tanks and healers above their share of builds.
